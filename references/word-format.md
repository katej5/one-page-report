# Word 파일 서식

보고서 내용은 `format.md`의 순서를 따르고, 파일은 아래 서식으로 만든다.

## 만드는 방법

- 코드 실행 도구로 .docx 파일을 만든다 (예: 파이썬 `python-docx`).
- 다 만든 뒤 내려받을 수 있는 링크나 파일로 준다.
- 파일을 만들 수 없는 환경이면 그렇다고 한 줄로 알리고, 보고서를 채팅에 보여준다.

## 파일 이름

`보고종류_제목_YYYYMMDD.docx` — 예: `결과보고_생성형AI시범사용_20261112.docx`

## 페이지

- A4 세로, 여백 위·아래·왼쪽·오른쪽 20mm
- 글꼴: 맑은 고딕 (없으면 기본 고딕 글꼴)
- 반드시 1쪽 안에 들어가게 한다. 넘치면 '주요 내용'부터 줄인다.

## 요소별 서식

| 요소 | 서식 |
|---|---|
| 제목 `[보고 종류] 제목` | 16pt, 굵게, 가운데 정렬 |
| 보고일 · 작성 · 보고 대상 줄 | 9.5pt, 회색, 오른쪽 정렬, 아래에 가는 선 |
| 칸 제목 (■ 한 줄 요약, ■ 1. 배경 …) | 12pt, 굵게, 남색(#1F3864), 위 여백 8pt |
| 한 줄 요약 내용 | 11pt, 굵게, 연한 회색 음영 상자 안에 |
| 본문 항목 | 10.5pt, 글머리 '-', 줄 간격 1.15 |
| ※ 확인 필요 | 9.5pt, 회색 |

표는 쓰지 않는다. 한 줄 요약 상자만 칸 하나짜리 표로 만들어도 된다.

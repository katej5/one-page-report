# 한 장 보고서 양식

아래 순서와 제목을 바꾸지 않는다. 칸에 쓸 내용이 없으면 '해당 없음'이라고 쓴다.

```
[보고 종류] 제목
보고일: YYYY.MM.DD  |  작성: (팀 · 이름)  |  보고 대상: (받는 사람)

■ 한 줄 요약
  - 결론 또는 결정이 필요한 것 한 문장

■ 1. 배경
  - 왜 이 보고를 하는지 (두 줄 이내)

■ 2. 주요 내용
  - 핵심 사실 3~5개 (숫자가 있으면 숫자를 앞에)

■ 3. 이슈 · 리스크
  - 문제가 되거나 될 수 있는 것 (없으면 '해당 없음')

■ 4. 다음 단계
  - 무엇을 / 누가 / 언제까지

※ 확인 필요
  - 자료에 없거나 애매해서 확인이 필요한 것
```

## 보고 종류별로 달라지는 점

| 보고 종류 | 한 줄 요약에 쓸 것 | 주요 내용의 초점 |
|---|---|---|
| 결과 보고 | 무엇이 끝났고 결과가 어떤지 | 결과 수치 · 목표 대비 |
| 주간 보고 | 이번 주 가장 중요한 진전 한 가지 | 한 일 · 다음 주 할 일 |
| 검토 보고 | 추천안과 결정이 필요한 것 | 선택지 비교 · 추천 이유 |
